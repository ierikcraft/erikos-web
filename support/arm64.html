Instalar ErikOS 14 Flex ARM64

Esta guía te ayudará a instalar ErikOS 14 Flex en tu Raspberry Pi utilizando la imagen de sistema oficial.

Imagen de sistema lista para descargar

Descargar ErikOS_14_Flex.img (.zip)

Versión: 1.0 | Arquitectura: ARM64 (RPi 4/5)

Requisitos previos

  • Tarjeta MicroSD (Mínimo 16GB, recomendado Clase 10).
  • Raspberry Pi 4 o Raspberry Pi 5.
  • Un ordenador con lector de tarjetas SD.

Instrucciones de instalación

1 Descarga la imagen: Haz clic en el botón superior para obtener el archivo .zip y descomprímelo para obtener el archivo .img.

2 Prepara el grabador: Recomendamos usar Raspberry Pi Imager o BalenaEtcher.

3 Graba la imagen: Abre el grabador, selecciona "Use Custom" (Elegir imagen propia) y selecciona tu archivo ErikOS_14_Flex.img. Selecciona tu tarjeta SD y pulsa en "Write".

4 Primer arranque: Introduce la SD en tu Raspberry Pi y enciéndela. El sistema iniciará automáticamente el escritorio.

Nota importante: Al iniciar por primera vez, verás un icono llamado "Instalador" en el escritorio. Ejecútalo para finalizar la configuración. Una vez terminado, el instalador se borrará solo para dejar el sistema limpio.
